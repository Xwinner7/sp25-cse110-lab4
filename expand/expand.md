The creators of JavaScript designed it to be loosely typed in order to enable rapid development and eliminate the need for lengthy type declarations, making it simple for beginners to learn and for developers to quickly design. Asynchronous features were introduced because web applications often need to perform tasks such as fetching data or waiting for user input without blocking the interface. The features such as callbacks and promises ensure that the page remains responsive while these operations are taking place.
3. Compiled languages are faster, but need a separate build process since they are transformed into machine code before running. Interpreted languages are executed line by line at runtime, which makes development faster but can slow execution.
JavaScript is interpreted, meaning it gives quick feedback when coding, but errors might only appear when the code runs and it can be slower than fully compiled languages.
